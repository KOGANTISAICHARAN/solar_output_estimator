Chronological Splitting vs Random Leakage

Standard random cross-validation randomly selects rows from the same afternoon. Because atmospheric conditions are heavily auto-correlated across consecutive 15-minute readings, random splitting introduces severe lookahead bias. The notebook partitioned the 34 days strictly chronologically (first 80% to train, last 20% for testing), simulating true real-world deployment.

2

TransformedTargetRegressor & SVR

Support Vector Regression using an RBF kernel was selected because solar power generation exhibits non-linear saturation at higher solar irradiance and thermal limits. Using TransformedTargetRegressor with StandardScaler normalizes both the 9 engineered features and the target kW range, guaranteeing gradient stability and preventing distance metric distortion.

3

95th-Percentile Calibration Thresholds

Rather than arbitrary error boundaries, Cell 73 splits the training window chronologically into a model-training set (80%) and an empirical calibration set (20%). It computes absolute residuals on the calibration set and calculates separate 95th-percentile error quantiles: 2,168.70 kW for Plant 1 and 4,673.13 kW for Plant 2. Residuals above these numbers represent true statistical outliers.
